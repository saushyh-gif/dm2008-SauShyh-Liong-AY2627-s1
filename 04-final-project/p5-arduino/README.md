Jar of fireflies

forest as bg, fireflies fly in a jar, when not in distressed sync flashing. firefly has trails behind. as the flies start settling down, flies flashing slowly start syncing. randomised flying pattern. upon hiting jar fly back.

Inputs:
3 sensors used
distance: represents the hand closing up to jar, flies fly away from hand

light: simulates day and night, when night firefly start glowing, the brighter it is the dimmer the firefly light (auto loop day and night)

force: simulates the shaking of jar, more force, shakes the jar more, distrubing the movement of the flying pattern and changing the firefly flashing pattern (keypressed)

adding more flyflies in the jar

States:
start
day
night
resting (sync)
distrubed
hit_jar
