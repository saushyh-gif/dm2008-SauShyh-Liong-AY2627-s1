# Class Activities

All the in-class activities for DM2008, sorted by week.

Weeks 1 to 5 are p5.js sketches, covering the basics like shapes, colours, variables, interaction, sound and simple animation. Each folder has the sketch files plus the images and screen recordings I submitted.

Weeks 8 and 9 move over to Arduino, starting with LEDs, then reading sensors, then using sensor values to control outputs. These folders have their own README with a bit more detail.
